# CHAOS BUDDIES

**A GRAVITY RUSH Studio original** — a colorful 3D party-arena prototype.

## Versions
- **v0.1–v0.6** — preserved early browser prototypes and experiments.
- **v0.7** — first Party Rumble arena experiment.
- **v0.8** — Showdown: clearly marked player character (cyan with crown and glowing ring), stronger targeted knockback, visible elimination when opponents are pushed beyond the arena, shorter 60-second rounds, faster shrinking arena, joystick movement and action cooldown indicators.

## Play
- GitHub Pages: https://tainguyen1234.github.io/chaos-buddies/
- **v0.8 direct play:** https://tainguyen1234.github.io/chaos-buddies/versions/v0.8/

## Controls
- Drag the large virtual joystick on the lower-left to move.
- **HÚC:** automatically targets the nearest opponent within range and launches them outward.
- **KHIÊN:** temporary protection.
- Cooldowns are shown on the action buttons.

## Notes
Single-player browser prototype with AI opponents, not online multiplayer. Three.js is loaded from a CDN and requires an Internet connection. The latest version still needs real-device playtesting and balance tuning.

## Repository
Versioned source files are stored under `versions/v0.x/index.html`. Earlier versions are preserved.
