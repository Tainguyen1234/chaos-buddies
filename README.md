# CHAOS BUDDIES

**A GRAVITY RUSH Studio original** — a colorful, funny mobile obstacle-runner prototype.

## Versions
- **v0.1** — first playable prototype: three-lane movement, jump, slide, obstacles, score.
- **v0.2** — adds collectible coins, hammer obstacles, combo feedback, pause/resume, and a locally saved personal best.

## Run
Open the version's `index.html` in a modern browser. The prototypes use HTML Canvas and vanilla JavaScript; no build step or external library is required.

## Controls
- Left / right: change lane
- Up: jump
- Down: slide
- On mobile: use the on-screen buttons

## Project status
Early playable prototypes. These are not yet native iOS/Android apps and do not yet include online multiplayer or actual 3D rendering.
