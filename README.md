# CHAOS BUDDIES

**A GRAVITY RUSH Studio original** — a colorful mobile 3D obstacle-runner prototype.

## Versions
- **v0.1** — first browser prototype with three-lane movement, jump, slide and obstacles.
- **v0.2** — collectible coins, hammer obstacle, combo feedback, pause/resume and local personal best.
- **v0.3** — first WebGL 3D scene with modeled BUBU, perspective track, 3D obstacles and touch controls.
- **v0.4** — animated running feet/body, fall pose, selectable BUBU/PIPI/ZUZU color styles and an extra gate obstacle.

## Play
- GitHub Pages: https://tainguyen1234.github.io/chaos-buddies/
- v0.4 source: `versions/v0.4/index.html`

## Controls
- Left / right: change lane
- Up: jump
- Down: slide
- On mobile: use the on-screen buttons

## Notes
These are browser prototypes, not native iOS/Android apps. The 3D versions load Three.js from a CDN and need an Internet connection. Online multiplayer is not implemented yet.
