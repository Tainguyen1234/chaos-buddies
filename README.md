# CHAOS BUDDIES

**A GRAVITY RUSH Studio original** — a colorful 3D party-arena prototype.

## Versions
- **v0.1–v0.5** — preserved early browser prototypes and character experiments.
- **v0.6** — Party Dash runner experiment with POMI, stars, combo and power-ups.
- **v0.7** — Party Rumble arena prototype: front-facing cute mascot, seven AI opponents, knockback dash, temporary shield, rotating sweeper, shrinking arena and last-buddy-standing win condition.

## Play
- GitHub Pages: https://tainguyen1234.github.io/chaos-buddies/
- **v0.7 direct play:** https://tainguyen1234.github.io/chaos-buddies/versions/v0.7/

## Controls
- Mobile: drag the large virtual joystick on the lower-left to move in any direction
- Keyboard: WASD / arrow keys
- ⚡ HÚC: dash into nearby opponents to knock them back
- 🛡 KHIÊN: temporary protection
- ⚡ HÚC: dash; automatically aims toward the nearest opponent when one is close
- 🛡 KHIÊN: temporary protection

## Notes
This is a single-player browser prototype with AI opponents, not online multiplayer. Three.js is loaded from a CDN and requires an Internet connection. Gameplay, collision tuning, device performance and visual polish still need playtesting.

## Repository
Versioned source files are stored under `versions/v0.x/index.html`. Earlier versions are preserved.
