# CHAOS BUDDIES

**A GRAVITY RUSH Studio original** — a colorful mobile 3D arcade runner prototype.

## Versions
- **v0.1–v0.5** — preserved browser prototypes and earlier character experiments.
- **v0.6** — new soft, friendly POMI mascot; denser obstacle patterns; collectible stars; combo chain; shield and magnet power-ups; progressive run speed; mission to collect 8 stars.

## Play
- GitHub Pages: https://tainguyen1234.github.io/chaos-buddies/
- v0.6 source: `versions/v0.6/index.html`

## Controls
- Left / right: change lane
- Up: jump
- Down: slide
- On mobile: use the on-screen buttons

## Notes
Browser prototype, not a native iOS/Android app. Three.js loads from a CDN and requires an Internet connection. Online multiplayer is not implemented.
